**Unofficial.** A community-maintained usage guide for the APIs around Liferay Data Platform (LDP). It is not an official Liferay publication and may be incomplete or outdated. For the official documentation, see [Managing API Access](https://learn.liferay.com/w/dxp/personalization/analytics-cloud/workspace-data/managing-api-access).

This site documents endpoints, parameters, payloads, and responses. It never sends requests: copy the code samples into a terminal or your own code.
